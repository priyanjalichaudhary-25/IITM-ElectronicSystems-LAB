# ScopeX Lab Sessions — Electronics Laboratory (IIT Madras BS Electronic Systems)

Hands-on electronics lab work for the **Electronics Laboratory**, performed on the **ScopeX Advanced Oscilloscope** (Bumblebee Instruments) — notably adapted on the fly from assignments originally written for the ADALM1000 / Analog Discovery workflow.

## 🏆 Highlight: ScopeX Challenges Log & Recommendations

**[ScopeX_challenges.pdf](./ScopeX_challenges.pdf)** — an original troubleshooting write-up documenting every practical issue hit while running Experiments 1–4 (Wheatstone bridge & filter study, 74LS163 digital counter, diode I-V/rectifier characterization) on ScopeX instead of the assignment's intended ADALM1000 hardware.

Covers:
- Root-cause analysis of ~13 distinct issues (signal generator limitations, undocumented CSV formats, channel scale mismatches, aliasing, Bode sweep ceiling, digital I/O pin confusion, and more)
- Concrete recommendations for the ScopeX development team
- Concrete recommendations for assignment redesign to match ScopeX's actual feature set

This reflects real debugging and technical documentation skill beyond just "completed the experiment" — diagnosing *why* something didn't work and proposing fixes at both the tool and assignment level.
