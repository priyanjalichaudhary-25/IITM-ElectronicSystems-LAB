# IIT Madras — BS in Electronic Systems

Coursework, lab work, and project documentation from the **BS in Electronic Systems** program at IIT Madras (hybrid degree program).

This repo is separate from my [JUIT VLSI Lab Portfolio](https://github.com/priyanjalichaudhary-25/VLSI-Lab-Portfolio) since the two are distinct degree programs with different curricula — this one tracks the broader Electronic Systems coursework (circuits, signals & systems, embedded programming, DSP, etc.) as I progress through Foundation → Diploma → BS levels.

## Repository Structure

| Folder | Description |
|---|---|
| [`scopex-lab-sessions/`](./scopex-lab-sessions) | Electronics Laboratory — weekly hands-on lab work using the ScopeX Advanced Oscilloscope, including an original troubleshooting/documentation write-up |

More folders will be added here as coursework progresses through further terms and lab courses.

## Program

- **Institution:** IIT Madras, Centre for Outreach and Digital Education
- **Degree:** BS in Electronic Systems (4-year, non-campus, online program)
- **Levels:** Foundation → Diploma → BS Degree
